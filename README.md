# Face Detection using OpenCV

This is a beginner-level computer vision project I worked on using Python and OpenCV.

The project uses a pre-trained Haar Cascade classifier to detect faces in an image and draw rectangles around the detected faces.

## Technologies Used

- Python
- OpenCV
- Matplotlib
- Jupyter Notebook

## What I Learned

- Loading and displaying images
- Converting images between BGR and RGB color spaces
- Converting images to grayscale
- Detecting faces with a pre-trained Haar Cascade classifier
- Drawing bounding boxes around detected faces

## How to Run

1. Install the required libraries:

   `pip install -r requirements.txt`

2. Place an image named `me.png` in the same folder as the notebook.
3. Open `face_detection.ipynb` in Jupyter Notebook.
4. Run the notebook cells in order.

## Notes

This project uses a pre-trained Haar Cascade classifier provided by OpenCV. It is an introductory project for exploring computer vision and image processing.
